# 🧩 UI Components

Before creating new UI elements, reuse these existing components to maintain consistency.

## 1. Typography & Headings
- `.vibe-heading`: The signature cursive font (`Hesmony`).
- `.vibe-text`: Standard muted body text.
- `.tagline`: Small uppercase text with wide letter-spacing.
- `.watermark`: Giant outline text used in section backgrounds.

## 2. Layouts
- `.section-padding`: Standard vertical padding for sections (`padding: var(--sp-xl) 0`).
- `.container`: Centered content wrapper with max-width 1400px.

## 3. Cards & Grids
- `.metric-item`: Used in the Project Info section. Features label, huge value, and desc.
- `.art-card`: Used in the Gallery. Image with hover zoom and `.glass-badge`.
- `.news-card`: Flex column card with image, date, title, and link.
- `.merch-card`: Simple white card with drop shadow for products.

## 4. Interactive Elements
- `.pill-btn`: Primary call-to-action button (outline style).
- `.theme-toggle`: Floating button for dark/light mode switch.
- `.contact-field`: Input fields with bottom borders only.
